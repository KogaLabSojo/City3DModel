# 熊本・通町筋 1/1000 模型 AR

熊本市役所の屋上に貼った ArUco マーカー 17 番を 8th Wall で読み、通町筋を中心にした市街地の情報を、模型の上に 1/1000 で重ねます。

市役所が原点です。実距離 100m は模型上の 10cm です。マーカー画像の右が東、上が北になる向きを基準にし、ずれているときは画面の方位で回します。

## 起動

```bash
npm install
npm run dev
```

パソコンでは <http://localhost:5173/?desk=1> で、カメラなしの配置確認ができます。

スマホでは同じ Wi-Fi で次を実行し、表示された `https://` のアドレスを開きます。証明書の警告は、開発用の自己署名なので続行してください。

```bash
npm run dev:phone
```

## 模型への合わせ

1. 調整画面の見本と、市役所屋上のシールの模様が同じか確認する。辞書は `DICT_4X4_50`、番号は 17 です。
2. 白い余白を含めた正方形の一辺を測り、「マーカーの一辺」に mm で入れる。初期値は 80mm です。
3. 画面の「北」が模型の北を向くまで、マーカー上辺の方位を回す。上辺が北なら 0°、東なら 90° です。
4. ピンを路上まで下げたいときは、屋上から地面までの模型の高さを mm で入れます。

地点の追加と文章の修正は `src/places.js` です。

## マーカーを作り直す

模型のシールが別の辞書のときは、辞書名を合わせてから追跡画像を再生成します。

```bash
python scripts/generate_marker.py --dict DICT_4X4_50 --id 17
npm run marker
```

`npm run marker` は見本画像の生成と、8th Wall のイメージターゲット化を続けて行います。
